# North Star

The north star is a desktop workspace for brand and marketing teams. It should feel like a precise editorial operations system rather than a generic AI dashboard: calm, inspectable, visually literate, and explicit about which decisions belong to people, policy, deterministic tools, and models.

## Product promise

The application lets a team build a durable brand brain, see which parts are canonical, and produce new work with a chosen degree of creative latitude. Every meaningful production decision remains explainable without turning the interface into a metadata form.

## Visual principles

- Put the work and its governing decisions on the same screen.
- Make locked and flexible elements visible before production begins.
- Treat canon, approvals, and prohibitions as operational state, not decorative badges.
- Use progressive disclosure for provenance, confidence, and version history.
- Distinguish deterministic composition from model generation in plain language.
- Keep review actions specific: approve an output, approve guidance, and promote to canon are separate actions.
- Prefer a restrained editorial rhythm, strong typography, warm neutral surfaces, and one controlled signal color.

## First anchor view

The first mockup focuses on a hybrid production job at the policy-review stage. It combines:

- the production request;
- selected mode and compiled policy;
- locked canonical assets;
- flexible world guidance;
- output preview;
- deterministic-composition record;
- drift and quality evaluation;
- approval and revision actions;
- proposed memory write-back.

This is the most useful anchor because it makes the product's central claim visible: policy changes system behavior while the underlying brand brain remains stable.
